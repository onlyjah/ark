## Practical limits

This is a substantial release candidate, not a public paid launch. Activation and real browser/mobile verification are still required.

- Saves are explicit. Queued save retries resume for the active document after unlock/reconnect. A general all-document background uploader, automatic cloud autosave, resumable attachments and full cloud sync cursor are not implemented.
- Encrypted attachment uploads, free collaborator grants/editing, anonymous private previews, key rotation/device revocation and native Android APK are not implemented. Paid member attachment upload is blocked instead of sending plaintext.
- Projects/folder paths, IDs, sizes, timestamps and billing metadata remain visible to the server. Private member Markdown content and titles are encrypted; this is not complete metadata concealment.
- Account signing/encryption keypairs are recovered on each authorized device through the same encrypted backup. Per-device independent keys and revocation are later work.
- Lost vault passphrase means lost decryption access. Existing vaults cannot be replaced through the key setup endpoint. Encrypted backup export is implemented; no plaintext private-key export is offered.
- Already-issued identity JWTs may remain usable until their short expiry after provider sign-out. The server checks current banned status on every request, but this is not immediate per-session JWT revocation.
- Public content uses a separate published object prefix in the existing private S3 bucket, served only through public publication routes. It is not a separate physical bucket or Neon/object branch. Paid storage is a logical user allocation in the existing bucket, with the inherited 5 GB quota.
- Personal document/project/revision metadata stays on persistent SQLite. Neon stores identity, accounts, purchases, events and encrypted key backups. Multi-replica metadata storage and migration of document metadata to Postgres are future work.
- Docker engine is unavailable; image build and physical Android/PWA behavior have not been verified. Bun bundle runtime tests passed.
